# Círculo Vet - Veterinaria Santa Raquel

Sitio web y landing page oficial de **Círculo Vet / Veterinaria Santa Raquel**, clínica veterinaria en La Florida, Región Metropolitana (Chile).

## Características

- 🐾 **Información institucional y servicios**: Hospitalización, UCI, cirugía, exámenes de laboratorio, ecografías y medicina general.
- 🚨 **Atención de Urgencias 24/7**: Canales de contacto directo y llamadas de emergencia.
- 📅 **Plan de Salud Preventivo**: Guías y calendarios de vacunación y controles para perros y gatos.
- 💬 **Integración WhatsApp**: Acceso rápido y botón flotante para agendamiento de horas.
- ✉️ **Formulario de contacto**: Conexión con base de datos en Supabase para almacenamiento de mensajes.
- ⚡ **Stack moderno**: Desarrollado con React 19, TypeScript, Tailwind CSS v4 y Vite.

## Requisitos previos

- Node.js 18+ (recomendado Node 20+)
- npm o pnpm

## Instalación y ejecución

1. Clonar el repositorio o descargar el proyecto.
2. Instalar dependencias:
   ```bash
   npm install
   ```
3. Configurar variables de entorno:
   Copiar `.env.example` a `.env` y configurar las credenciales de Supabase:
   ```bash
   cp .env.example .env
   ```
4. Iniciar en modo desarrollo:
   ```bash
   npm run dev
   ```
5. Compilar para producción:
   ```bash
   npm run build
   ```
6. Verificar tipos TypeScript:
   ```bash
   npm run typecheck
   ```
